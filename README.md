# Δίκτυο σπιτιού: οδηγίες εγκατάστασης

Το σύστημα έχει δύο κομμάτια: το **AdGuard Home** (ο «φρουρός» που μπλοκάρει τα sites για όλο το σπίτι)
και το **app** (η δική σου οθόνη ελέγχου, `http://IP-ΤΟΥ-ΥΠΟΛΟΓΙΣΤΗ:8080`).

## Τι χρειάζεσαι
Έναν υπολογιστή που μένει πάντα ανοιχτός στο σπίτι (Raspberry Pi 3/4/5, παλιό laptop ή mini PC) με Docker.
Σε Raspberry Pi: `curl -sSL https://get.docker.com | sh`

## Βήμα 1: Σταθερή IP
Ο υπολογιστής πρέπει να έχει πάντα την ίδια IP (π.χ. 192.168.1.50). Στο router, στις ρυθμίσεις DHCP,
δέσμευσε (reserve) μια IP για τον υπολογιστή αυτόν.

## Βήμα 2: Ξεκίνα το AdGuard Home
```bash
cd family-net
docker compose up -d adguard
```
Άνοιξε `http://192.168.1.50:3000` και ακολούθησε τον οδηγό. **Σημαντικό:** στο πρώτο βήμα βάλε
*Admin Web Interface* → port **3000** (όχι 80). Φτιάξε username/κωδικό και σημείωσέ τα.

> Αν ο υπολογιστής είναι Ubuntu και το port 53 είναι πιασμένο (systemd-resolved), πες μου και σου δίνω την οδηγία.

## Βήμα 3: Ξεκίνα το app
```bash
cp .env.example .env
nano .env          # συμπλήρωσε τους κωδικούς
docker compose up -d --build
```
Άνοιξε `http://192.168.1.50:8080` και μπες με `APP_USER` / `APP_PASS`.

## Βήμα 4: Στρέψε το σπίτι στο AdGuard (το πιο σημαντικό)
Στο router, στις ρυθμίσεις **DHCP / LAN**, βάλε ως **DNS server** την IP του υπολογιστή (192.168.1.50)
και **κανένα δεύτερο DNS**. Μετά ξανασυνδέσου από κάθε συσκευή (ή κλείσε/άνοιξε το Wi-Fi τους).
Έλεγχος: στο AdGuard → *Query Log* πρέπει να βλέπεις κίνηση από τις συσκευές.

## Βήμα 5: Όνομα για κάθε συσκευή (για τα «μόνο για αυτόν»)
Στο AdGuard → *Settings → Client settings → Add client* δώσε όνομα χωρίς κενά (π.χ. `mama`, `dad`) και την IP
ή το MAC της συσκευής. Τότε στο app γράφεις `dad` στο «Επίτρεψε μόνο σε αυτή τη συσκευή».
Βάλε στο router σταθερή IP και σε αυτές τις συσκευές, αλλιώς αλλάζει η IP τους.

## Πώς δουλεύει η καθημερινή χρήση
- **Μπλόκαρε**: πάτα Netflix, YouTube κ.λπ. ή γράψε οποιοδήποτε site.
- **Ξεμπλόκαρε για όλους** για 15 λεπτά, 1 ώρα, 3 ώρες. Μετά ξαναμπλοκάρει μόνο του.
- **Επίτρεψε μόνο σε μία συσκευή** (π.χ. στη δική σου) ενώ για τους άλλους μένει μπλοκαρισμένο.
- Το app γράφει τους κανόνες του μέσα στο AdGuard (Filters → Custom filtering rules) ανάμεσα στις γραμμές
  `! BEGIN/END FamilyNetControl`. Ό,τι άλλο έχεις εκεί δεν πειράζεται.

## Πώς θα το παρακάμψουν (και τι να κάνεις)
1. **Δικό τους DNS στο κινητό/browser** (DoH, «Private DNS»): στο router μπλόκαρε εξερχόμενη κίνηση στα ports 53 και 853
   εκτός από τον υπολογιστή σου. Στο Chrome/Firefox το DoH κλείνει από τις ρυθμίσεις ή πολιτική.
2. **VPN**: μπλόκαρέ τα στη λίστα (π.χ. nordvpn.com, expressvpn.com, protonvpn.com). Δεν είναι 100%.
3. **Δεδομένα κινητής (4G/5G)**: το φίλτρο δουλεύει μόνο στο Wi-Fi του σπιτιού.

## Ασφάλεια
Το app έχει πλήρη έλεγχο του φίλτρου. Μην το ανοίξεις στο internet (μην κάνεις port forwarding στο 8080 ή 3000)
και βάλε δυνατό `APP_PASS`. Για να το ανοίγεις και εκτός σπιτιού, χρησιμοποίησε WireGuard ή Tailscale.
